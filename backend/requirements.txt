# Target: Python 3.11+ (Render's version is pinned in render.yaml)
#
# IMPORTANT - install order on Linux:
#   Plain `pip install torch` on Linux pulls ~2.5 GB of NVIDIA CUDA wheels,
#   which is useless without a GPU and will not fit on a free Render instance.
#   Install the CPU-only build FIRST, then this file:
#
#       pip install --index-url https://download.pytorch.org/whl/cpu torch torchvision
#       pip install -r requirements.txt
#
#   build.sh does exactly that for Render. On macOS and Windows the normal
#   wheels are already CPU-only, so `pip install -r requirements.txt` is enough.
